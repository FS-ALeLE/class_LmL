# ChatGPT 이미지 생성 가이드: 「여섯 마을 물 거래 대소동」

앱을 더 세련되게 만들 그림을 ChatGPT로 만드는 방법입니다.
그림을 만들어 `assets/img/` 폴더에 올려 주시면, 앱에 넣고 화면 디자인도 그림에 맞춰 다듬겠습니다.

---

## 0. 먼저 알아 둘 원칙 4가지

1. **눈금, 컵, 항아리 물 높이처럼 수학과 관련된 그림은 코드로 그린 것을 그대로 둡니다.**
   AI 그림은 눈금 간격이나 크기 비율이 정확하지 않아서 오개념이 생길 수 있습니다. AI 그림은 배경, 삽화, 캐릭터, 장식에만 씁니다.
2. **그림 안에 글자를 넣지 않습니다.** AI가 만든 한글이나 숫자는 대부분 깨집니다. 'L 각인' 같은 글자는 앱에서 그림 위에 얹습니다.
   → 모든 프롬프트 끝에 `no text, no letters, no numbers`를 붙입니다.
3. **한 대화방에서 계속 만듭니다.** 같은 방에서 이어서 요청해야 그림체가 통일됩니다. 마음에 드는 첫 그림이 나오면 다음 요청에서 "방금 그림과 같은 스타일로"라고 덧붙입니다.
4. **특정 작가나 스튜디오, 캐릭터 이름(예: ○○ 스타일)은 쓰지 않습니다.** 저작권 문제가 생길 수 있고, 공개수업 자료로도 깔끔하지 않습니다.

---

## 1. 스타일 고정 프롬프트 (대화 첫 메시지로 붙여 넣기)

```
지금부터 초등학교 3학년 수학 수업용 웹앱에 쓸 그림을 여러 장 만들 거야.
모든 그림은 아래 스타일을 똑같이 지켜 줘.

[세계관] 사막 한가운데 오아시스가 있고, 물이 마르지 않는 마법 항아리가 있다.
여섯 마을(해바라기·선인장·낙타·별빛·야자수·조개 마을)이 항아리 물을 나누어 쓴다.

[스타일] 부드러운 2.5D 그림책 일러스트, 둥글고 단순한 형태, 은은한 그림자,
과슈 질감이 살짝 있는 매트한 느낌, 따뜻한 사막 팔레트
(모래색 #F6E7C8, 해질녘 주황 #F2A541, 오아시스 청록 #2E9CCA, 진한 갈색 #3B2A1A),
밝고 친근한 분위기, 아이들이 좋아할 귀여움, 과하지 않은 디테일.

[공통 규칙] 그림 안에 글자·숫자·간판 문구 없음(no text, no letters, no numbers).
사람 얼굴 대신 동물·사물 캐릭터 위주. 워터마크 없음.

이해했으면 "준비 완료"라고만 답해 줘.
```

## 2. 만들 그림 목록

ChatGPT가 만들 수 있는 크기는 **정사각형(1024×1024)**, **가로형(1536×1024)**, **세로형(1024×1536)** 세 가지입니다.
아래 **파일 이름 그대로** 저장해 주시면 앱에 바로 연결하기 쉽습니다.

### ★ 꼭 필요한 그림 (우선 제작)

| # | 파일 이름 | 크기 | 배경 | 쓰이는 곳 |
|---|---|---|---|---|
| 1 | `bg_landscape.png` | 가로 1536×1024 | 그림 | 교사 진행판 전체 배경 |
| 2 | `bg_portrait.png` | 세로 1024×1536 | 그림 | 학생 태블릿 배경 |

## 3. 그림별 프롬프트 (복사해서 사용)

> 스타일 고정 프롬프트를 보낸 **같은 대화방**에서 하나씩 보냅니다.

### ① 배경 (가로·세로)

```
배경 그림을 만들어 줘. 가로형(1536x1024).
넓은 사막 언덕과 멀리 작은 오아시스, 맑은 하늘과 옅은 구름.
화면 가운데는 글자와 버튼이 올라갈 자리라서 비어 있고 밝고 단순해야 해(대비 낮게, 흐릿하게).
주요 사물은 가장자리와 아래쪽에만 작게. no text, no letters, no numbers.
```

```
방금 배경과 같은 스타일과 색감으로 세로형(1024x1536) 버전을 만들어 줘.
가운데는 비우고, 아래쪽에 모래 언덕과 작은 야자수, 위쪽은 하늘. no text.
```

### ② 이야기 4장면

```
이야기 1장면, 가로형(1536x1024): 사막 한가운데 반짝이는 오아시스와
그 옆에 놓인 커다란 둥근 도자기 항아리(입구가 좁고 몸통이 둥글다).
항아리에서 은은한 빛과 작은 반짝임이 난다. 평화롭고 신비로운 분위기. no text.
```

```
이야기 2장면, 같은 스타일: 오아시스를 둘러싼 여섯 개의 작은 마을.
각 마을 입구에 상징이 보인다(해바라기, 선인장, 낙타, 별, 야자수, 조개).
마을 대표 동물 캐릭터들이 항아리 주위에 모여 손을 맞잡고 약속하는 장면. 따뜻하고 즐거운 분위기. no text.
```

```
이야기 3장면, 같은 스타일: 같은 항아리 앞에서 여섯 마을 캐릭터들이
각자 크기가 다른 컵을 들고 서로 "우리가 맞아!" 하듯 팔을 흔들며 다투는 장면.
얼굴은 귀엽게 볼이 부은 정도, 무섭지 않게. 말풍선은 빈 모양만 있고 글자 없음. no text.
```

```
이야기 4장면, 같은 스타일: 여섯 마을과 오아시스 사이 협곡에 무지갯빛으로 반짝이며
놓이기 시작한 나무 다리. 캐릭터들이 희망찬 표정으로 다리를 바라본다. 해질녘 하늘. no text.
```

### ③ 여섯 마을 엠블럼 (투명 배경, 6장 통일)

```
마을 엠블럼 6개를 같은 디자인 규칙으로 하나씩 만들 거야.
규칙: 정사각형(1024x1024), 투명 배경 PNG, 둥근 방패 모양 배지 안에 상징 하나,
두꺼운 테두리, 살짝 입체감, 가운데 정렬, 여백 충분히. no text.
첫 번째: 해바라기 마을, 노란색(#F2B705) 테두리, 상징은 해바라기 한 송이.
```

이어서 상징과 색만 바꿔 요청합니다.

| 파일 | 마을 | 테두리 색 | 상징 |
|---|---|---|---|
| village2 | 선인장 마을 | 초록 #4CAF50 | 귀여운 선인장 |
| village3 | 낙타 마을 | 갈색 #C47F3C | 쌍봉낙타 |
| village4 | 별빛 마을 | 보라 #7E57C2 | 반짝이는 별 |
| village5 | 야자수 마을 | 청록 #00897B | 야자수 |
| village6 | 조개 마을 | 산호색 #E57373 | 소라 껍데기 |

```
같은 규칙으로 두 번째: 선인장 마을, 초록색(#4CAF50) 테두리, 상징은 귀여운 선인장.
```

### ④ 안내 캐릭터 (투명 배경, 같은 캐릭터 4가지 표정)

```
안내 캐릭터를 만들어 줘: 사막여우 '들이 박사'. 작은 탐험가 모자와 가방,
허리에 작은 계량컵을 매달고 있다. 전신, 정면에서 살짝 비스듬히, 투명 배경 PNG, 정사각형. no text.
첫 번째 표정: 기본(손 흔들며 환영).
```

이어서 같은 캐릭터로 표정만 바꿉니다.
- `guide_hello.png`: 기본, 손 흔들기
- `guide_great.png`: 칭찬, 엄지 척과 반짝임
- `guide_think.png`: 생각, 턱 괴고 물음표 모양 반짝임(글자 아님)
- `guide_cheer.png`: 응원, 두 팔 들고 점프

```
방금 그 '들이 박사'와 완전히 같은 캐릭터(모자·가방·색 동일)로, 표정과 자세만 '칭찬: 엄지 척, 눈을 감고 웃음, 주변에 반짝임'으로 바꿔 줘. 투명 배경. no text.
```

### ⑤ 각인 메달 틀 (선택, 투명 배경)

```
게임 보상 메달 틀 4개를 같은 규칙으로 만들 거야. 정사각형, 투명 배경,
둥근 메달 + 아래 리본, 가운데는 글자를 얹을 수 있게 비워 둔 단색 원.
1번: 청록 메달(물방울 장식). no text.
```

- 2번: 하늘색 메달, 작은 물방울 장식
- 3번: 금색 메달, 반짝임 장식
- 4번: 갈색 가죽 장부 느낌 메달

### ⑥ 기타 (3장)

**`bridge_done.png`** (정리 단계)
```
가로형, 같은 스타일: 완성된 무지개빛 나무 다리 위에서 여섯 마을 캐릭터와 사막여우 '들이 박사'가 함께 축하하는 장면. 불꽃놀이처럼 반짝이는 물방울. no text.
```

**`title_scene.png`** (입장 화면 대표 그림)
```
입장 화면 맨 위에 넣을 대표 그림, 가로형(1536x1024), 같은 스타일:
오아시스 옆 반짝이는 마법 항아리를 가운데 두고, 사막여우 '들이 박사'가 항아리 옆에서 손을 흔들며 환영한다.
여섯 마을의 상징(해바라기, 선인장, 낙타, 별, 야자수, 조개)이 항아리를 둥글게 둘러싸고 작게 놓여 있다.
위쪽 1/3은 제목 글자를 얹을 자리라서 맑은 하늘만 단순하게 비워 둬. 모험이 시작되는 설레는 분위기. no text.

**`app_icon.png`** (탭 아이콘)
```
앱 아이콘, 정사각형: 반짝이는 마법 항아리 하나가 가운데, 둥근 모서리 사각 배경(모래색에서 주황 그라데이션). 단순하고 작은 크기에서도 알아보기 쉽게. no text.

## 4. 결과가 마음에 안 들 때 쓰는 말

| 문제 | 이렇게 요청하기 |
|---|---|
| 글자가 들어감 | "그림 속 글자를 모두 지워서 다시 만들어 줘" |
| 스타일이 달라짐 | (마음에 든 그림을 첨부하고) "이 그림과 똑같은 그림체·색감으로" |
| 배경이 투명하지 않음 | "배경을 완전히 투명하게 한 PNG로 다시 줘" |
| 너무 복잡함 | "디테일을 절반으로 줄이고 형태를 더 단순하게" |
| 가운데가 복잡함(배경) | "가운데 영역을 비우고 흐릿하게, 사물은 가장자리로" |
| 캐릭터가 바뀜 | "모자·가방·털 색은 첫 번째 그림과 완전히 같게" |

2. 다음 둘 중 편한 방법으로 보내 주세요.
   - **GitHub 웹에서 올리기**: 저장소 → 브랜치 `claude/serene-feynman-fjm8g9` 선택 → `Add file` → `Upload files` → 파일을 끌어 놓고 경로를 `assets/img/`로 지정 → Commit
   - **이 대화에 바로 첨부하기**: 제가 받아서 저장소에 넣겠습니다.
3. 파일이 크면(1장 2 MB 이상) 제가 웹용(WebP)으로 줄여서 태블릿에서도 빨리 뜨게 하겠습니다.

> 일부만 먼저 보내셔도 됩니다. **배경 2장 + 마을 엠블럼 6장 + 캐릭터 1장**만 있어도 분위기가 크게 바뀝니다.
