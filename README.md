# 🏜️ 여섯 마을 물 거래 대소동 — 초등 3학년 수학 「들이」 수업 앱

초등학교 3학년 수학 **들이** 단원을 재구성한 공개수업용 웹앱입니다.
교사가 진행판에서 단계를 넘기면 학생 태블릿 화면이 멘티미터처럼 함께 넘어갑니다.

| 화면 | 주소 | 누가 |
|---|---|---|
| 학생 화면 | `/` (index.html) | 학생 태블릿 (2인 1대 권장) |
| 교사 진행판 | `/teacher` (teacher.html) | TV·전자칠판에 띄우는 교사용 |

## 단원 재구성 (3차시 + 단원 계획)

| 차시 | 주제 | 비고 |
|---|---|---|
| 1 | 누구 그릇이 더 클까? (직접·간접 비교) | |
| **2 ★공개** | **단위가 필요해!** (임의 단위 → L·mL → 눈금 읽기) | 이 앱 |
| 3 | 들이 탐정단 (단위 바꾸기 + 생활 속 어림) | 과제 ‘우리 집 들이 탐정’ 활용 |
| (4) | 들이의 덧셈과 뺄셈 | 단원 계획에만 표시 |

## 공개 차시 흐름 (40분)

| 단계 | 시간 | 앱 단계 | 내용 |
|---|---|---|---|
| 도입 | 5′ | 입장 → 이야기 시작 | 여섯 마을 이야기, 학습 문제 확인 |
| 활동1 | 10′ | 물 거래 대소동 | 마을마다 크기가 다른 컵으로 항아리 재기 → 결과가 다름 → 단위의 필요성 |
| 활동2 | 10′ | 단위의 탄생 | L·mL 읽기·쓰기(따라 쓰기), **1 L = 1000 mL**, ‘□ L □ mL ↔ □ mL’ 바꾸기 |
| 활동3 | 10′ | 평화의 눈금 | 눈금 읽기 4단계 → 마법 항아리 = 1 L 200 mL → 평화의 다리 |
| 정리 | 5′ | 평화의 다리 | 배운 내용 정리, 스스로 평가, 과제 안내 |

## 수업 당일 사용법

1. 교사: `https://(배포주소)/teacher` 를 TV에 띄우면 **방 코드 4자리**와 QR 코드가 나옵니다.
2. 학생: `https://(배포주소)/` 접속(QR) → 방 코드 → 마을 → 태블릿 번호 → **출발!**
3. 교사가 **다음 ▶** 을 누르면 모든 학생 화면이 같이 넘어갑니다.
   - **👀 주목**: 학생 화면을 잠시 가리고 “선생님을 봐 주세요!” 표시
   - 활동1·3의 마을 카드를 누르면 결과를 손으로 입력할 수도 있습니다(네트워크 문제 대비).
   - ⚙️ 메뉴: 결과 초기화 / 새 방 / **방 닫기**(수업 후 기록 삭제)
4. **도우미 모드**(입장 화면 체크): 글자 크게, 숫자 입력 → 고르기 문제, 짝 맞추기 수 줄이기, 🔊 소리 읽기.

### 연습·비상 모드
- `?mode=local` — 같은 컴퓨터의 여러 탭끼리 동기화(Firebase 없이 연습·시연). 예: `/teacher?mode=local` + `/?mode=local`
- `?mode=manual` — 동기화 없이 각자 화면을 넘기는 수동 모드. Firebase 연결에 실패하면 자동으로 수동 모드가 됩니다.

## Firebase 보안 규칙 (꼭 한 번 적용)

Firebase 콘솔 → Realtime Database → **규칙** 탭에 [`database.rules.json`](database.rules.json) 내용을 붙여 넣고 **게시**합니다.
- 4자리 방 코드 아래만 읽고 쓸 수 있고, 전체 방 목록은 읽을 수 없습니다.
- 학생 이름 등 개인정보는 저장하지 않습니다(마을 번호·태블릿 번호만).
- 교사가 새 방을 만들 때 하루 지난 방은 자동으로 지워집니다.

## 배포 (Vercel)

1. Vercel → **Add New Project** → 이 GitHub 저장소 선택
2. Framework Preset: **Other**, Build Command 비움, Output Directory 비움(루트)
3. Deploy. 이후 GitHub에 push할 때마다 자동 배포됩니다.

## 내용 고치기

문구·문제·마을·컵 크기는 대부분 [`js/config.js`](js/config.js) 한 파일에 모여 있습니다.

| 파일 | 역할 |
|---|---|
| `js/config.js` | Firebase 설정, 마을·컵, 이야기, 눈금 문제, 자기평가 문항 |
| `js/student.js` | 학생 화면 (활동1·2·3·정리) |
| `js/teacher.js` | 교사 진행판 |
| `js/widgets.js` | 문제 부품(객관식, 숫자 입력, L·mL 입력, 따라 쓰기, 짝 맞추기) |
| `js/art.js` | 항아리·컵·비커·다리 그림(SVG) |
| `js/sync.js` | 실시간 동기화(Firebase / 로컬 / 수동) |
| `docs/수업안_들이_공개수업.hwpx` | 수업안(양식 그대로) + 활동지 ①②와 예시 답안 |
| `docs/tools/build_lesson_plan.py` | 양식에 내용을 채워 수업안 hwpx를 다시 만드는 스크립트 (`python3 docs/tools/build_lesson_plan.py`, lxml·Pillow 필요) |
| `docs/양식_참고/` | 받은 양식과 참고 완성본 |

로컬에서 확인: 저장소 폴더에서 `python3 -m http.server 8000` 실행 후 `http://localhost:8000/teacher?mode=local` (cleanUrls가 없으므로 로컬에선 `/teacher.html?mode=local`).
